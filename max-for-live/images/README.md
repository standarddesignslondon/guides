# Device screenshots

Drop screenshots here using the exact filenames listed in the main README, e.g.
`cascade.png`, `oram.png`. Then re-run `python3 build_site.py` from the folder
above — pages with an image swap the dashed placeholder for the picture, and
the index cards pick up a thumbnail.

`.png`, `.jpg`, `.jpeg` and `.webp` all work.

On a Mac: `Cmd+Shift+4`, press `Space`, click the device window — or drag a
rectangle around the device face in Live.
