Dither

The image is reduced by this factor before dithering and each result pixel becomes a cell×cell block. 1 = full resolution; larger = coarser, more visible dither.
50
Pattern size, angle and depth apply to the halftone, cross-hatch and modulation algorithms only.
100
Diffusion strength and serpentine apply to the error-diffusion algorithms only. Lower strength behaves more like a plain threshold.

Colours

Ink pixels take a colour from the shadows → midtones → highlights ramp according to the tone underneath; paper stays paper.
Red, green and blue are each dithered on their own, so every pixel is one of eight colours. Diffusion, tone and grain apply per channel.
50
Nearest palette colour per pixel with the chosen algorithm blending between them. Spread is how far ordered and pattern algorithms push a pixel towards neighbouring colours.

Presets

Choosing a saved preset loads it immediately. Save with a new name to add one, or with the name of the selected preset to overwrite it. Presets are kept in the plugin's data folder and survive updates.
Select a pixel layer and press Render. The result goes on a new layer above it; the source is left untouched.
