Patches

Size is width plus height. With 30 and 100, a 50×40 patch (90) or a 10×25 patch (35) is allowed; 60×70 (130) or 5×24 (29) is not.
Caps how elongated a patch can be. 1 = always square, 3 = up to 3:1 either way.

Placement

Overhanging patches always keep at least one pixel on the canvas.

Sample from

Iterative mode samples the visible composite, so earlier patches in the same pass can be re-copied. Hide any other layers you don't want sampled.
Select the base layer, then Run. Patches go on a layer named "Scatter" directly above it; later passes add to the same layer.
