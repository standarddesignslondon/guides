HEXRACK

a databending effects rack

▾Rack

Devices run top to bottom, like an effects rack: the bent file from one is the input to the next. Click a slot to edit it in the Device and Stage sections. Add puts a new device below the selected one.

▾Device

▾Stage

Rows from / Rows confine this device to a band of the file, like selecting part of it in a hex editor; what the device does inside the band stays inside it. Write back to a single channel keeps the other two from the input, so a bend can hit the red alone.

▾Output

Preview bends a small copy of the picture (pixel distances scaled to match) and writes it, enlarged, to a "Hexrack preview" layer; byte-level effects can't scale exactly, so the full Render will differ in detail. Render does it at full size. Update re-renders the last result in place. Everything works on 8-bit RGB bytes; 16-bit documents are converted on the way in and out.
